1. TUJUAN & RINGKASAN
---------------------------------------------------------------------
Membuat website pribadi untuk jurnal trading yang:
  - Menyimpan semua trade (pair, arah, waktu entry/exit, P/L, hasil,
    R:R, risk, alasan entry, emosi, screenshot).
  - Menampilkan DASHBOARD STATISTIK yang lengkap.
  - Punya KALENDER JURNAL (P/L per hari, klik hari untuk lihat detail).
  - Menyimpan CATATAN per trade dan catatan harian/mingguan.
  - Bisa dibuka dari HP dan laptop, data sama di semua perangkat.

Prioritas yang kamu minta:
  (1) Dashboard statistik lengkap   <- paling penting
  (2) Kalender jurnal
  (3) Catatan
  (4) Input jurnal: cukup bisa input dulu, form yang cantik belakangan

Template Notion yang sekarang jadi acuan kolom data:
  Pair | Date - Entry | Date - Exit | Direction | Profit / Loss |
  Result | R:R | Risk | Reason - Entry | Note - Emotions | Progress |
  Screenshots


---------------------------------------------------------------------
2. PRINSIP DESAIN
---------------------------------------------------------------------
  - Tema gelap sebagai default (cocok dengan Notion-mu), ada opsi terang.
  - Hijau = profit, merah = loss, abu = break even. Konsisten di mana saja.
  - Bahasa antarmuka: Indonesia. Istilah trading tetap Inggris
    (Win Rate, Profit Factor, Drawdown, dst).
  - Zona waktu tampilan: WIB (Asia/Jakarta). Di database disimpan UTC.
  - Mobile-first: semua halaman nyaman di HP (dibuat sebagai PWA,
    bisa dipasang di layar utama HP).
  - Filter global di semua halaman: rentang tanggal, akun, pair, arah.
  - Setiap statistik yang datanya sedikit diberi label "sampel kecil"
    (misalnya di bawah 30 trade), supaya tidak salah menyimpulkan.
  - Cepat: angka statistik dihitung sekali lalu di-cache, bukan dihitung
    ulang tiap buka halaman.


---------------------------------------------------------------------
3. REKOMENDASI TEKNOLOGI
---------------------------------------------------------------------
PILIHAN UTAMA (yang saya sarankan)
  Frontend : Next.js (React) + Tailwind CSS
  Grafik   : Recharts atau Apache ECharts
  Database : Supabase (Postgres) -> database, login, dan penyimpanan
             screenshot dalam satu layanan
  Hosting  : Vercel (atau Netlify / Cloudflare Pages)
  Bentuk   : PWA (bisa di-install di HP)

  Alasan:
    - Supabase memberi database SQL sungguhan, sehingga statistik bisa
      dihitung dengan query yang rapi.
    - Login & penyimpanan gambar sudah tersedia, tidak bikin dari nol.
    - Vercel + Supabase punya free tier yang biasanya cukup untuk 1 orang.
      (Syarat free tier bisa berubah, cek lagi saat mendaftar.)

ALTERNATIF 1 - Tanpa server (lokal saja)
  Aplikasi web yang menyimpan data di browser (IndexedDB) + tombol
  export/import file.
    + Paling sederhana, tanpa akun, 100% privat.
    - Data hanya ada di satu perangkat/browser. Kalau browser terhapus,
      data bisa hilang (harus rutin backup).
    - Tidak bisa sinkron HP <-> laptop.

ALTERNATIF 2 - Google Sheets sebagai database
  Website membaca/menulis ke Google Sheets.
    + Familiar, mudah diedit manual.
    - Lambat untuk data banyak, ribet soal izin, upload screenshot
      kurang enak.

ALTERNATIF 3 - Tetap pakai Notion sebagai database
  Website membaca data dari Notion API.
    + Data tetap di Notion.
    - Butuh server kecil untuk menyimpan token, query statistik lambat,
      dan ada batas request. Tidak cocok untuk statistik yang berat.

KESIMPULAN: pilih Utama (Next.js + Supabase + Vercel).

5. MODEL DATA
---------------------------------------------------------------------
TABEL accounts (akun trading)
  id, nama (mis. "Funded 50K"), tipe (funded/live/demo), mata uang,
  saldo_awal, tanggal_mulai, target_profit (opsional),
  max_daily_loss (opsional), max_total_loss (opsional), aktif

TABEL trades
  id, account_id
  pair                (teks, mis. XAUUSD)
  direction           (Buy / Sell)
  entry_time, exit_time   (timestamp UTC; tampil WIB)
  entry_price, exit_price, stop_loss, take_profit   (opsional)
  lot_size                (opsional)
  profit_loss             (angka, dalam mata uang akun)
  result                  (TP / SL / BE / Manual)
  planned_rr              (R:R rencana, mis. 2)
  risk_percent            (mis. 0.25)
  risk_amount             (dalam $, dihitung otomatis dari saldo jika ada)
  r_multiple              (hasil dalam satuan R, dihitung otomatis)
  reason_entry            (teks)
  emotion                 (pilihan: Tenang, FOMO, Takut, Serakah, Revenge...)
  emotion_note            (teks bebas)
  mistakes / lessons      (teks, opsional)
  followed_plan           (ya/tidak, opsional)
  status                  (Open / Done)
  created_at, updated_at

TABEL trade_screenshots
  id, trade_id, file_path, caption, urutan (mis. "sebelum"/"sesudah")

TABEL tags + trade_tags
  Tag bebas untuk setup/strategi (mis. "VWAP", "ORB", "News").

TABEL daily_notes
  id, tanggal, rencana_pagi, review_malam, mood, catatan_bebas

TABEL weekly_reviews (tahap lanjut)
  id, minggu_ke, hal_yang_berjalan_baik, kesalahan, target_minggu_depan

CATATAN PENTING TENTANG R:R DI TEMPLATMU
  Di fotomu satu trade berisi Result = SL tetapi R:R = 1. Artinya kolom
  R:R kemungkinan R:R RENCANA, bukan hasil sebenarnya. Maka:
    - planned_rr disimpan sebagai input.
    - R aktual dihitung = profit_loss / risk_amount
      (risk_amount = saldo x risk_percent, atau diisi manual).
    - Kalau saldo tidak diisi, statistik berbasis R aktual ditandai
      "butuh saldo awal" dan tetap bisa jalan memakai asumsi:
      SL = -1R, TP = +planned_rr R (perkiraan kasar).

6. STATISTIK LENGKAP
---------------------------------------------------------------------
A. RINGKASAN UTAMA
  - Total trade, jumlah menang / kalah / BE
  - Win rate        = menang / (menang + kalah)  [BE dilaporkan terpisah]
  - Net P/L         = total profit + total loss
  - Gross profit, gross loss
  - Profit factor   = gross profit / |gross loss|
  - Expectancy ($)  = rata-rata P/L per trade
  - Expectancy (R)  = rata-rata R per trade
  - Rata-rata menang, rata-rata kalah
  - Payoff ratio    = rata-rata menang / |rata-rata kalah|
  - Break-even win rate = 1 / (1 + payoff ratio)
    (win rate minimum agar impas; dibandingkan dengan win rate nyata)
  - Trade terbaik, trade terburuk
  - Rata-rata R:R rencana, rata-rata risk %
  - Rata-rata durasi trade (menang vs kalah)
  - Trade per hari / per minggu

B. STREAK & KONSISTENSI
  - Streak menang/kalah sekarang
  - Streak menang terpanjang, streak kalah terpanjang
  - Hari profit vs hari loss, persentase hari profit
  - Hari terbaik, hari terburuk
  - Minggu dan bulan terbaik / terburuk
  - Win rate bergulir (rolling 20 trade terakhir)
  - Konsistensi: profit hari terbesar dibanding total profit
    (penting untuk aturan konsistensi di beberapa prop firm)

C. EQUITY & DRAWDOWN
  - Kurva equity (kumulatif P/L, dari saldo awal)
  - Max drawdown ($ dan %), tanggal terjadinya
  - Drawdown saat ini
  - Lama drawdown & lama pemulihan
  - Recovery factor = net profit / max drawdown
  - Simpangan baku P/L, Sharpe/Sortino sederhana (opsional,
    diberi penjelasan singkat agar tidak menyesatkan)

D. PEMECAHAN (BREAKDOWN) - semua menampilkan: jumlah trade, win rate,
   net P/L, profit factor, expectancy
  - Per pair
  - Per arah (Buy vs Sell)
  - Per hari dalam seminggu
  - Per jam (WIB)
  - Per sesi (Asia / London / New York, jam bisa diatur di pengaturan)
  - Per hasil (TP / SL / BE / Manual)
  - Per ukuran risk (kecil / sedang / besar)
  - Per durasi (scalp <15 menit, intraday, swing)
  - Per bulan
  - Per tag/setup/strategi
  - Per akun

E. ANALISIS EMOSI & DISIPLIN
  - Win rate dan P/L per emosi (mis. "FOMO" rata-rata -$18 per trade)
  - "Biaya emosi": total P/L dari trade ber-emosi buruk
  - Trade yang mengikuti plan vs tidak
  - Hubungan jumlah trade per hari dengan hasil
    (apakah overtrading setelah loss?)
  - Trade setelah loss beruntun: hasilnya lebih buruk atau tidak?
  - Kata yang paling sering muncul di catatan kesalahan

F. VISUALISASI
  - Equity curve + drawdown
  - Batang P/L harian/mingguan/bulanan
  - Donat/batang distribusi hasil (TP/SL/BE)
  - Heatmap jam x hari (di mana kamu paling profit)
  - Histogram distribusi R (sebaran hasil trade)
  - Scatter risk vs hasil
  - Perbandingan dua periode (bulan ini vs bulan lalu)

PRINSIP: setiap kartu statistik bisa diklik untuk melihat daftar trade
yang membentuk angka itu (drill-down).

7. KALENDER JURNAL
---------------------------------------------------------------------
Tampilan:
  - Kalender bulanan; tiap hari menampilkan P/L, jumlah trade, dan warna
    (hijau/merah, pekat sesuai besar nominal).
  - Kolom ringkasan per minggu di sisi kanan (P/L, jumlah trade, win rate).
  - Ringkasan bulan di atas (total P/L, win rate, hari profit/loss).
  - Mode tahunan: heatmap seperti kalender kontribusi GitHub.

Interaksi:
  - Klik hari -> panel samping berisi daftar trade hari itu, catatan
    harian, dan screenshot.
  - Tombol "+ Tambah trade" langsung dengan tanggal terpilih.
  - Penanda hari yang BELUM dijurnal tetapi ada aktivitas
    (membantu disiplin menjurnal).
  - Hari libur/tidak trading ditandai netral.
  - Filter akun dan pair berlaku di kalender.

Aturan perhitungan:
  - Trade masuk ke hari berdasarkan waktu EXIT (atau entry, bisa diatur
    di pengaturan) dalam zona waktu WIB.

8. CATATAN & JURNAL HARIAN
---------------------------------------------------------------------
Level catatan:
  1. Catatan per trade: alasan entry, emosi, kesalahan, pelajaran.
  2. Catatan harian: rencana pagi (bias, level penting, batas risk hari
     ini) dan review malam (apa yang berjalan baik/buruk, mood).
  3. Review mingguan: ringkasan, pelajaran, target minggu depan.

Fitur:
  - Editor dengan format sederhana (tebal, daftar, centang).
  - Tag dan pencarian teks penuh ("cari semua catatan yang menyebut FOMO").
  - Templat catatan yang bisa diubah.
  - Aturan pribadi (checklist) yang bisa dicentang sebelum/ sesudah
    trade: mis. "Sudah cek news?", "Risk <= 0.5%?". Hasil centang dipakai
    di statistik disiplin.
  - Riwayat perubahan sederhana (supaya catatan lama tidak hilang).

11. FITUR KHUSUS AKUN FUNDED (OPSIONAL, TAHAP LANJUT)
---------------------------------------------------------------------
Karena kamu memakai akun funded, ini bisa sangat berguna:
  - Pelacak daily loss dan total drawdown terhadap batas aturan
    (angka batas diisi manual sesuai prop firm-mu).
  - Progres menuju profit target.
  - Cek aturan konsistensi (mis. profit hari terbesar vs total).
  - Peringatan jika risk hari ini mendekati batas.
  - Hitung sisa "ruang" sebelum menyentuh limit.
Catatan: aturan tiap prop firm berbeda dan bisa berubah, jadi semua
angka batas diisi dan diperiksa sendiri oleh kamu.

12. KEAMANAN & PRIVASI
---------------------------------------------------------------------
  - Login wajib (email + password, atau tautan ajaib via email).
  - Pendaftaran umum DIMATIKAN setelah akunmu dibuat.
  - Row Level Security di database: hanya akunmu yang bisa
    membaca/menulis data.
  - Bucket screenshot privat.
  - Kunci rahasia (API key) hanya di pengaturan server, tidak pernah
    ada di kode yang dikirim ke browser.
  - Jangan simpan password broker atau data kartu di website ini.
  - Backup: tombol export semua data (CSV + JSON) di Pengaturan,
    disarankan dijalankan rutin (mis. sebulan sekali).
  - Pertimbangkan 2FA untuk akun login.

16. RISIKO & CATATAN JUJUR
---------------------------------------------------------------------
  - Statistik hanya menggambarkan masa lalu. Dengan trade yang sedikit,
    angka seperti win rate dan profit factor sangat mudah menyesatkan.
    Itu sebabnya ada label "sampel kecil".
  - Statistik yang bagus bukan jaminan hasil ke depan; dashboard ini
    alat refleksi, bukan saran trading.
  - Dashboard lengkap itu bagus, tetapi manfaat terbesar jurnal tetap
    datang dari mencatat KONSISTEN dan jujur, terutama bagian emosi dan
    kesalahan. Website sebaiknya membuat pencatatan semudah mungkin,
    karena itu form input tetap perlu dipoles di Fase 5.
  - Free tier layanan bisa berubah. Pantau batas penyimpanan dan
    lakukan backup rutin.
  - Membuat dashboard selengkap ini butuh waktu bertahap. Lebih baik
    selesaikan Fase 1-3 dulu dan pakai, baru lanjut Fase 4+.
  - Data trading itu sensitif. Jangan lewati bagian keamanan (12).
